# iBarangay

A PHP and MySQL barangay information and service-management platform for residents and local administrators.

## Implemented areas

- Resident registration and identity verification
- Role-based administrative access
- Barangay records, events, blotter workflows, and document requests
- Email verification and password recovery
- PDF and email delivery workflows
- Audit trails, backup, and restore utilities

## Local setup

Run the project through XAMPP or another PHP/MySQL environment, import the supplied database schema, and keep database, SMTP, payment, and third-party credentials in local environment configuration. Never commit real passwords or API keys.

## Security notice

Any credentials previously committed to Git history must be considered compromised and rotated even after they are removed from current files.
